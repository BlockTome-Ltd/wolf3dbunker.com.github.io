Seems like these days, everybody wants to build their own Wolfenstein games! If you're a fledgling Wolfenstein developer like I was six years ago, you'll find these tools and resources to be immensely helpful.

Utilities
  Name Description OS
FloEdit 1.1 (link) The ultimate Wolfenstein editor. Handles levels, walls, sprites, sounds, VGAGRAPH images. Some source code knowledge may be required for certain functions. Handles Wolf and Spear, shareware and registered.

 Windows
Mapedit 8.4 The last version -- and by far the most versatile -- in the venerable Mapedit series begun by Bill Kirby in 1992, this is still my editor of choice. Edits six games: Wolf3D, Spear, Blake Stone (original and Planet Strike), Corridor 7, and Operation: Body Count.

 DOS
Mapedit 4.2 An early "legacy" version of Bill Kirby's original Wolfenstein editor. Version 4.2. Edits shareware or registered Wolfenstein.

DOS
Mapedit 7.0 An early "legacy" version of Bill Kirby's original Wolfenstein editor. Version 7.0. Shareware editing was disabled in this release.

 DOS
Mapedit 7.2 A "hacked" version of Mapedit, allowing editing of the shareware/demo versions of Wolf and Spear.

 DOS
Pascal EXE Patcher If you are getting Runtime Error 200 when you try to run Mapedit, you need this patch. Place in same directory as Mapedit and run TPPATCH MAPEDIT.EXE. Output will be in German (no, I'm not kidding).

 DOS
Wolfedit 2.1 Bill Kirby's original DOS-based graphics editor for Wolfenstein. Made obsolete by FloEdit (see top of page).

 DOS
Wolfsnd 1.0 Quirky sound effects extraction/insertion program for Wolfenstein 3D (registered) only. Seems to have a problem with the GT-distributed VSWAP. Made obsolete by FloEdit (see top of page).

 DOS
Wolfaud 1.1 Console-based sound effects extraction/ insertion program for Wolfenstein 3D shareware only. By Bill Neisius of DMAUD fame, the good ol' DOS-based sound editor for Doom. (Anybody remember that?) DOS
Wolfmap 1.6 A MapEdit clone, this time written in c++. It has all the features of MapEdit plus more, such as being about to convert map versions! By ???DOS
