A screenshot from the Wolfenstein level editor, Mapedit.

   On this page I have a selection of Wolfenstein 3D add-ons for you to download and play. Some of them feature source code modifications, others do not. All of them include new levels, while some have graphics and sound changes as well. Most of the links here are to external sites, because I don't have the disk space to spare to store all the files on my host server. If a link to a file on my server (read: not someone else's server) is down, and I'll tell you where to get the file if I can. I also have links to download the various Wolfenstein utilities if you want to do your own add-ons. This includes Mapedit (the level editor), Wolfedit for graphics, and WolfSnd/WolfAud for sounds. If you want the source code, head on over to my source code section. I also give you a link to a compiler you can use to build your own EXEs!

   On my list of add-on level packages for Wolfenstein, I provide a little key to let you know what the package contains. There are various icons which will appear to be "lit" (bright yellow) or "unlit" (dark gray) depending on what sort of new resources the add-on includes. Next, there will be a link for acquiring the add-on. If it says "Go to homepage", the link will take you to the a webpage where you can download the add-on. If it says "Download", it is a direct download link from either my server or another server. Lastly, if I have played the add-on myself, I might give it a rating of 1-5, 5 being the best. These will be represented by a number of small circles. The number of "lit" circles equals the rating I gave the add-on. I usually rank primarily according to level design.

Schabbs 2000  
50 levels
   GFX   SND   EXE   [ Homepage ]   • • • • •
                     
The add-on that started it all! One of the first out there (maybe the first) to have new keys and other EXE changes, this package has 50 consecutive levels, split into several distinct units. (Each unit has a different theme and objective). Plenty of new graphics and excellent level design. Quite difficult to play. This is a stand-alone game that does not require you to have Wolfenstein already. I highly recommend this one.

Utilities

FloEdit  
Multi Editor
  [ Coming Soon ]
The ultimate in Wolfenstein editing. This brand new editor by Florian Stöhr will do it all -- levels, walls, sprites, sounds, even the images in VGAGRAPH.WL6 -- and possibly more stuff too. Works on Wolfenstein 3-D and Spear of Destiny. Still in beta stage now, but the full version should be out soon. Please don't ask for a copy. Flo has plenty of beta testers as it is.

Mapedit v8.4  
Level Editor
  [ Download ]
The last version in the venerable Mapedit series begun by Bill Kirby and modified by a team of others, this is the editor I prefer. Lots of nice features, and it edits five games: Wolf3D, Spear, Blake Stone, Corridor 7, and Operation Body Count. (Why you'd want to make levels for that last one, I have no idea.)

Pascal EXE Patcher  
EXE Patcher
  [ Download ]
If you are getting Runtime Error 200 when you try to run Mapedit (or a variety of other older programs), you need this patch. Older programs compiled in Pascal 7 can't be run on P6-based computers above 200 MHz. This will correct that fault.

WolfEdit 2.1  
Graphics Editor
  [ Download ]
Pretty much the one and only graphics editor for Wolfenstein and Spear, but it is a pretty good one at that. Made by Bill Kirby, original author of Mapedit.

WolfSnd  
Sound Editor
  [ Download ]
Sound effects extraction/insertion program for Wolfenstein 3D only. Currently I know of no sound editor for Spear, oddly enough. Seems to have a problem with the GT-distributed VSWAP file. Use an older Apogee one for best results. For actual waveform editing, I recommend Cool Edit Pro.

WolfAud 1.1  
Sound Editor
  [ Download ]
Sound effects extraction/insertion program for Wolfenstein 3D shareware only. By Bill Neisius of DMAUD fame, the good ol' DOS-based sound editor for Doom. (Anybody remember that?)
