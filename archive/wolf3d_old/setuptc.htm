If you're reading this, I'm guessing you want to learn how to set up Borland Turbo C++ 3.0 and build your own EXEs, but either you couldn't figure it out yourself or you just didn't want to bother. Well, today I wrote up a step-by-step file on how to get TC up and running and build a functioning EXE. If you follow all these steps exactly, everything should work fine. If it doesn't -- please don't come crying to me! Okay, here we go.

INSTALLING TURBO C++ 3.0 AND COMPILING THE WOLF3D SOURCE

  1. Download TC.ZIP to any directory on your system.
  2. Create a directory on your hard drive called TC30. Whatever drive it is doesn't matter. For this example I'll be assuming you created C:\TC30.
  3. Put TC.ZIP into the new TC30 directory.
  4. If you have PKUNZIP for DOS, type pkunzip tc.zip -d. Or, if you have Winzip, extract TC.ZIP's contents to the TC30 directory, and make sure you enable "Use Folder Names" so the original directory structure of the zipfile is kept intact upon extraction.
  5. Open your AUTOEXEC.BAT file (it's in C:\) in a text editor.
  6. Find the line that says SET PATH= or PATH=. Go to the end of that line. Add this: ;C:\TC30\BIN;. (The first ; might be there already. Just make sure there's one between each directory entry.) If you have no path statement, add this line to AUTOEXEC.BAT: SET PATH=C:\TC30\BIN;%PATH%. (No spaces anywhere after the =.) What this does is makes it so any programs in the TC30\BIN directory can be run from any directory on the system. That directory is where all the various compiler programs are stored and if Turbo C can't get at them from wherever you're running it, it'll freak out.
  7. Save changes to AUTOEXEC.BAT and reboot the computer.
  8. Go to a DOS box and navigate to the directory where your Wolfenstein source code is stored. For example, C:\SOURCE\WOLF.
  9. Type TC. If nothing happens, you messed up something, probably in step 6. If it doesn't work, type PATH and see if C:\TC30 (or whatever your TC directory is) is in the output.
  10. If TC starts up, you should see a blue-gray screen with a menu bar on top, and a rectangular cyan window at the bottom labeled: Project: WOLF3D. There should be a whole bunch of files in the project window. So far, so good. But before we can compile the source, we need to change some things.
  11. Select Options --> Directories...
  12. Change the Include and Library directories to reflect where you put the compiler. For instance, if you installed TC to C:\TC30, make the Include directory C:\TC30\INCLUDE and the Library directory C:\TC30\LIB. The output directory should be OBJ. This is where all the compiled .OBJ files will be placed, as well as the finished WOLF3D.EXE. It's also where you need to put the 2 pre-compiled .OBJ files from my website; more on this later.
  13. Now scroll down in the project window (bottom of the screen) until you find SIGNON.OBJ and GAMEPAL.OBJ. Their location, as according to the project window, will be C:\SOURCE\WOLF\OBJ. If this is not the path to your source code OBJ directory, like if you installed the source to a different drive or path, you'll need to change these files. You can't edit their location in the project file, so you'll have to remove these 2 entries and insert 2 new ones. Highlight SIGNON.OBJ and press Delete (the keyboard button). Do the same with GAMEPAL.OBJ. Now press the Insert key. The "Add to Project List" dialog box will appear. Navigate to your source code's OBJ directory or type the full path in the name box. You will probably have to change the "*.C" in the name box to "*.OBJ" or you won't see the files you want in the list display. Once you finally find the right directory, SIGNON.OBJ and GAMEPAL.OBJ should be the only OBJ files in there. Double-click them to add them to the project window, and then click Done.
  14. You should be ready to compile now! Select Compile --> Build All to compile all C files and link them into WOLF3D.EXE automatically. Hopefully it will be a success!
  15. If everything worked and the build was successful, you still aren't done. You have to get the files ID_CA.OBJ and ID_SD.OBJ from my website and put them in your source code OBJ directory. Get them here. This particular zipfile contains only these two .OBJ files. Since you built an EXE already, files by their names will already exist in your OBJ directory, as well as a bunch of other .OBJ files. You want to overwrite the existing ID_CA.OBJ and ID_SD.OBJ with the 2 files from TCOBJ.ZIP.
  16. Now, run TC again. Select Compile --> Link. Do not Build All, or the 2 properly-compiled .OBJ files you just copied in will be overwritten again with the bad ones TC generates.
  17. Now, take the WOLF3D.EXE in your OBJ directory and see if it works! Remember to use the VGA files from my site or the graphics will look screwy.
  18. In the future, as you make code changes, you will have to compile each file one at a time by highlighting it in the project window and pressing Alt+F9. When you've done that to all the files you changed, select Compile --> Link. Never use Build All or you'll mess up ID_CA.OBJ and ID_SD.OBJ!
  19. That should be it.... Good luck, and have a good time! :)
