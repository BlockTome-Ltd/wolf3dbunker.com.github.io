TUTORIAL 5: Seamless Level Progression w/Ratio Reporting

   Of all the things people ask me how to do with the Wolfensten source code, probably the #1 most asked thing is, "How do I create seamless level progression and have ratio reporting after every level?" Well, after getting hammered with this one for so long, I decided to take a day of my time and get something really nice put up as to how you, the Wolfenstein programmer, can accomplish this. Unlike the previous tutorials I've posted up, this process involves six different files of code. As the changes necessary are so widespread, I can't really write a step-by-step tutorial. Instead, I've provided each of the 6 files for you, and you can take a look at the modifications I've done and learn how to implement them yourself (or for ultimate laziness, just compile my files).

   The 6 files that need modifications are: WL_INTER.C, WL_MAIN.C, WL_MENU.C, WL_MENU.H, and WL_DEBUG.C. The last one is just for a convenience issue but I threw it in for your added pleasure. :) Okay, click on each of the names below to take a look at the file and see what I did to it. To find the blocks of code where modifications were made, do a search for the text BJ3CODE by pressing Control+F in your browser (if that doesn't work, try F3). Each code modification is preceeded by a commented line with this word on it, so searching for it will take you right to the things that were changed. Alternatively, you click the final link which will let you download a ZIP file containing all of the above files. Enjoy your meal!

VIEWABLE SOURCE FILES

  • WL_INTER.C -- Handles the intermission screen, where you'll see the ratios
  • WL_MAIN.C -- Controls how the secret levels will be handled (for more precise control than in Tutorial 3!)
  • WL_MENU.C -- Changes to this file cause the game to skip the episode select screen
  • WL_MENU.H -- Just commenting out 1 line to avoid compiler error
  • WL_DEBUG.C -- Changes here let you warp to any level in the game (1-60)
